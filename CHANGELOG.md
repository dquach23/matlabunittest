# Changelog

All notable changes to matlabunittest are recorded here.  Phase numbers
match the corresponding `PHASE<N>_HANDOFF.md` files.

The autogen is **scaffolding plus invariants**, not "tests that know
your spec."  Each phase tries to flip more autogenerated tests from
Failed/Incomplete to Pass without introducing per-project knowledge
into the +autotest package.

## Phase 13 -- 2026-05-06

### Added
- `+autotest/StateInitializer.m::candidateMethodCalls(model, fixtureProvider)`:
  detects multi-arg state-init methods (`add*`, `set*`, `register*`,
  `attach*`, `insert*`, `put*`) and returns full call expressions with
  arguments resolved through FixtureProvider.  All-or-nothing arg
  resolution; varargin always disqualifies a candidate.
- `+autotest/StateInitializer.m::tryResolveArgs(method, fixtureProvider)`:
  helper that returns `{}` unless every positional argument resolves
  to a non-empty literal via FixtureProvider.literalForArg or
  InputSampler.scalarFor (typed fallback).
- `+autotest/FixtureProvider.m`: new heuristics for `padchar` /
  `fillchar` (returns `'*'`), `celllocation`, `columnnames`, and the
  `endsWith` form of `tablename` / `columnname` / `cellref`.  Stringy
  exact-name list extended with `endsWith(lname, 'titletext' |
  'headertext' | 'subtitle')`.
- `CHANGELOG.md` (this file).
- `PHASE14_HANDOFF.md`.

### Changed
- `+autotest/TestWriter.m::appendClassTests` now consults
  `candidateMethodCalls` instead of `candidateMethods` for the
  TestMethodSetup state-init prelude, so multi-arg setters are
  invoked with their resolved args.
- `+autotest/TestWriter.m::appendFunctionMethods` early-gate
  condition now consults `candidateMethodCalls`, so classes whose
  state-init is multi-arg-only also drop the `testSkipped_<name>`
  short-circuit.

### Results
- removal_redaction_tool: 857 -> 934 Pass (+77), 54 -> 42
  Incomplete (-22%), 0 Failed.  TableMetadata 5/16 -> 81/83.
- matlabunittest/examples: unchanged at 95/95 Pass, 0 Failed.

## Phase 12 -- 2026-05-06

### Added
- `+autotest/InputSampler.m::isDOMName / isDOMType / domExpr / tempDOM`:
  in-memory XML DOM fixture for methods that take DOM args (named
  `*DOM` / `*Document` / `dom` / `doc` / `xmlDoc` / `xmlNode`, or
  typed as `org.w3c.dom.*` / `matlab.io.xml.dom.*`).
- `+autotest/FixtureProvider.m`: DOM-name and XML tag-name
  substitution; `tagname` / `elementname` / `attrname` /
  `attributename` / `nodename` / `partname` -> `'a'`.

### Changed
- `+autotest/TestWriter.m`: fopen-lifecycle gate bypass in
  `appendFunctionMethods` -- when the StatefulReason is purely
  `'fopen()'` (no `'leaves'`), drop the early-gate skip; the
  constructor itself establishes the live handle.  Phase 11's
  stateful-smoke try/assumeFail wrap converts any synthetic-input
  throws to Incomplete.
- `+autotest/TestWriter.m::randomArgsExpr` substitutes DOM args
  with `tempDOM(testCase)` instead of `rand(...)`.
- `+autotest/TestWriter.m::appendPropertyTestsForFcn` exempts DOM
  args from the anyOpaque skip.

### Results
- removal_redaction_tool: 746 -> 857 Pass (+111), 96 -> 54
  Incomplete (-44%), 0 Failed.  ReportWriter 4/20 -> 85/89.
- matlabunittest/examples: unchanged.

## Phase 11 -- 2026-05-05

### Added
- `+autotest/StateInitializer.m`: zero-arg state-init prelude
  detection (build* / load* / scan* / prepare* / populate* / init* /
  setup* / configure* / compile*).  TestMethodSetup runs each
  candidate inside its own try/catch.
- Stateful-smoke and stateful-randomized try/assumeFail wraps in
  TestWriter so non-validation throws become Incomplete instead
  of Failed when the called method needs state the autogen could
  not pre-build.

### Results
- removal_redaction_tool: 542 -> 746 Pass (+204), 0 Failed.
- matlabunittest/examples: 74 -> 95 Pass.

## Phase 10 -- 2026-05-05

### Added
- `+autotest/InputSampler.m::isFileIDName / fileIDExpr / tempFileID`:
  fileID-named args (`fid`, `fileID`, `*ID` typed numeric scalar)
  resolve to a real `fopen()`-backed handle with addTeardown
  cleanup.

### Results
- removal_redaction_tool: 480 -> 542 Pass.

## Phase 9 -- 2026-05-04

### Added
- mlapp UIFigure detection by TYPE rather than by NAME; tolerates
  apps that rename the figure component (e.g. `ReportRedactionToolUIFigure`).

## Phase 8 -- 2026-05-03

### Added
- Doc-example test extraction from `% Example:` blocks in help text.

## Phase 7 -- 2026-05-03

### Added
- `_autotest/known_real_signal.txt` per-target opt-out: tests listed
  here become `testSkipped_<name>` Incomplete with the user's
  reason text instead of failing.
- Stringy-implicit smoke ladder reduction (Phase 7 Option 4): when an
  arg name was overridden to `string` by Phase 6, only emit the scalar
  smoke (vector/matrix variants reliably crash project regexp/fprintf
  chains).

## Phase 6 -- 2026-05-03

### Added
- Name-driven string Type override in `+autotest/InputSampler.m`:
  args named `text` / `pattern` / `name` / `message` / `str` etc.
  with no explicit `arguments` block declaration get Type='string'
  forced, stopping edge tests from feeding `[]` / `NaN` into regexp
  / fprintf chains.
- fopen-lifecycle stateful detection.

## Phase 5 -- 2026-05-02

### Added
- Property get/set round-trip tests for public mutable properties.
- Per-method randomized property tests.

## Phase 4 -- 2026-05-02

### Added
- Edge-case test ladder per arg: `empty`, `nan`, `inf`, `zero`,
  `neg`, `large`, `small`.
- Constructor existence + smoke tests.

## Phase 3 -- 2026-05-01

### Added
- `+autotest/MlappParser.m`: extract embedded classdef from
  App Designer .mlapp files.
- Per-callback synthetic event-struct invocation.

## Phase 2 -- 2026-05-01

- `_autotest/user_tests/` sticky stubs that survive regeneration.
- JUnit XML and TAP output formats.

## Phase 1 -- 2026-04-30
